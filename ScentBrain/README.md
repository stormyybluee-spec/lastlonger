# Sion Scent Brain (build 0.1)

The master node for Sion: a person types any brief and gets three formulas back
(Scent 1 Creative, Scent 2 Accurate, Scent 3 Luxury) built from a 64-cartridge palette.

`index.html` is the whole brain in one file:

- **Offline engine**: lexicon, 24-dimension olfactive map, three heads, tier-by-tier formulator
- **Claude layer**: sends the brief, rules and palette to Claude for a richer reading
- **Validator**: palette IDs, caps, beauty floor and dosing are enforced in local code, so the model never has the last word
- **Plan**: architecture, translation rules, hard briefs, palette sizing, learning loop, landscape, roadmap

Caps and dose levels are planning placeholders. Check every formula against current IFRA Standards and supplier certificates before selling anything.
